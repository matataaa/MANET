Import this in ATAK (Import Manager → this file) once. It installs a self-refreshing Network Link that pulls node positions and signal-quality links from this node. Configure the GPS source (own receiver / manual / take over an EUD's position) in the applet's config page first. The refresh interval is baked into this download at the time you get it — if you change it later, re-download and re-import to apply it.
