Find this in the ATAK device's own self-marker (Settings → Device Preferences), or read it off an incoming CoT event from that device.
How often ATAK re-fetches the overlay. Matches the mesh registry's own ~15s gossip tick by default — lower doesn't get you fresher edges.
Takes effect on next import, not retroactively: this value is only written into the Network Link when you download the ATAK package. ATAK reads it once, at import time, and keeps polling on that cadence from then on — it does not come from /topology.kml itself on each fetch. Changing this and restarting the applet does not change the polling rate for a package someone already imported; re-download and re-import in ATAK to apply a new interval.
